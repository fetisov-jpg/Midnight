# Midnight — документация

Документация проекта **Midnight API** — сервиса сбора статистики по СУБД и кэшам.

## Содержание

| Файл | Назначение |
|---|---|
| [overview.md](overview.md) | Что это, для кого, верхнеуровневая архитектура, стек |
| [api.md](api.md) | Полный справочник HTTP-эндпоинтов с контрактами запрос/ответ |
| [data-model.md](data-model.md) | Модель конфигурации и данных, схемы PlantUML |
| [data-flow.md](data-flow.md) | Sequence-диаграммы потоков данных для ключевых сценариев |
| [known-issues.md](known-issues.md) | Известные несостыковки, TODO, что отрефакторено при подготовке документации |

## Быстрый старт

```bash
# 1. Зависимости
uv sync

# 2. Настройка окружения (правь под себя)
cp src/.env.example src/.env  # или отредактируй существующий src/.env

# 3. Запуск в режиме разработки
uv run dev

# Документация API:
# Swagger UI — http://localhost:8000/docs
# ReDoc      — http://localhost:8000/redoc
```
